# Edit Profiles Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a dedicated `/profiles/$id` edit page that lets users update an existing profile's name, env vars, CLI flags, config isolation, and auto-restart, then save via the existing `PUT /api/profiles/:id`.

**Architecture:** Frontend-only. A new param route (`profiles_.$id.tsx`, mirroring the existing `sessions_.$id.tsx` pattern) loads the profile from the shared `["profiles"]` React Query cache and renders a controlled `ProfileFields` form seeded from the row. Saving issues `PUT /api/profiles/:id` with the same body shape as create, invalidates the cache, and navigates back. The create form on `/profiles` is refactored to reuse the same `ProfileFields` + parsing helpers so env/flags parsing has one source of truth.

**Tech Stack:** React 19, TanStack Router (file-based routes, `routeTree.gen.ts` regenerated by the Vite plugin), TanStack Query v5, shadcn/ui (Base-UI primitives), lucide-react icons, bun test for helpers.

```ts
import type { ProfileRow } from "@/types/profile";

/**
 * Live form state shared by the profile create form and edit page.
 * `envText`/`flagsText` are the raw textarea values, parsed only on submit.
 */
export interface ProfileFormValue {
  name: string;
  envText: string;
  flagsText: string;
  isolation: boolean;
  restartOnExit: boolean;
}

/** Empty form state — the starting point for the create form. */
export function emptyProfileForm(): ProfileFormValue {
  return { name: "", envText: "", flagsText: "", isolation: false, restartOnExit: false };
}

/**
 * Seeds a form from a profile row: pretty-prints env JSON and joins the flags
 * array back into one flag string per line.
 */
export function profileFormFromRow(row: ProfileRow): ProfileFormValue {
  let envText = "";
  if (row.envJson) {
    try {
      envText = JSON.stringify(JSON.parse(row.envJson) as Record<string, string>, null, 2);
    } catch {
      // Corrupt stored JSON — surface it raw rather than dropping it.
      envText = row.envJson;
    }
  }
  const flags: string[] = row.flagsJson ? (JSON.parse(row.flagsJson) as string[]) : [];
  return {
    name: row.name,
    envText,
    flagsText: flags.join("\n"),
    isolation: row.configIsolation === 1,
    restartOnExit: row.restartOnExit === 1,
  };
}

/**
 * Parses the env textarea into an object. Throws on invalid JSON so callers
 * can surface "Env vars must be valid JSON".
 */
export function parseEnvJson(envText: string): Record<string, string> {
  return envText.trim() ? (JSON.parse(envText) as Record<string, string>) : {};
}

/**
 * Parses the flags textarea (one flag string per line) into CLI tokens.
 * Each line is split on whitespace so multi-word flags (e.g. "--effort max")
 * become individual tokens.
 */
export function parseFlags(flagsText: string): string[] {
  return flagsText
    .split("\n")
    .map((f) => f.trim())
    .filter(Boolean)
    .flatMap((f) => f.split(/\s+/));
}
```

```tsx
import { useMutation, useQueryClient } from "@tanstack/react-query";
import { createFileRoute, Link, useNavigate, useParams } from "@tanstack/react-router";
import { useState } from "react";
import { ProfileFields } from "@/components/profile-fields";
import { Button } from "@/components/ui/button";
import { Card, CardContent, CardDescription, CardHeader, CardTitle } from "@/components/ui/card";
import { useProfiles } from "@/hooks/use-profiles";
import { apiFetch } from "@/lib/api";
import { parseEnvJson, parseFlags, profileFormFromRow, type ProfileFormValue } from "@/lib/profile-form";
import type { ProfileRow } from "@/types/profile";

export const Route = createFileRoute("/profiles_/$id")({
  component: EditProfilePage,
});

function EditProfilePage() {
  const { id } = useParams({ from: "/profiles_/$id" });
  const { data: profiles, isLoading } = useProfiles();

  if (isLoading) {
    return (
      <main className="mx-auto w-full max-w-2xl p-6">
        <p className="text-muted-foreground">Loading…</p>
      </main>
    );
  }

  const profile = profiles?.find((p) => p.id === id);

  if (!profile) {
    return (
      <main className="mx-auto w-full max-w-2xl p-6">
        <Card>
          <CardHeader>
            <CardTitle>Profile not found</CardTitle>
            <CardDescription>The profile may have been deleted.</CardDescription>
          </CardHeader>
          <CardContent>
            <Button asChild variant="outline">
              <Link to="/profiles">Back to profiles</Link>
            </Button>
          </CardContent>
        </Card>
      </main>
    );
  }

  // Keyed by id so each profile gets a fresh form instance: navigating from
  // /profiles/:a to /profiles/:b remounts this form (TanStack reuses the route
  // component across param changes, so without the key the old snapshot would
  // shadow the new profile on the first render).
  return <ProfileEditor key={profile.id} profile={profile} />;
}

function ProfileEditor({ profile }: { profile: ProfileRow }) {
  const { id } = useParams({ from: "/profiles_/$id" });
  const navigate = useNavigate();
  const queryClient = useQueryClient();
  const [form, setForm] = useState<ProfileFormValue>(() => profileFormFromRow(profile));
  const [error, setError] = useState<string | null>(null);

  const mutation = useMutation({
    mutationFn: (v: ProfileFormValue) =>
      apiFetch(`/api/profiles/${id}`, {
        method: "PUT",
        body: JSON.stringify({
          name: v.name.trim() || "Untitled",
          env: parseEnvJson(v.envText),
          flags: parseFlags(v.flagsText),
          configIsolation: v.isolation,
          restartOnExit: v.restartOnExit,
        }),
      }),
    onSuccess: () => {
      void queryClient.invalidateQueries({ queryKey: ["profiles"] });
      navigate({ to: "/profiles" });
    },
    onError: (err) => setError(err instanceof Error ? err.message : "Failed to save"),
  });

  return (
    <main className="mx-auto w-full max-w-2xl p-6">
      <Card>
        <CardHeader>
          <CardTitle>Edit profile</CardTitle>
          <CardDescription>Update {profile.name} for the {profile.harnessId} harness.</CardDescription>
        </CardHeader>
        <CardContent className="space-y-4">
          <ProfileFields value={form} onChange={setForm} />
          {error && <p className="text-destructive text-sm">{error}</p>}
          <div className="flex justify-end gap-2">
            <Button variant="outline" onClick={() => navigate({ to: "/profiles" })} disabled={mutation.isPending}>
              Cancel
            </Button>
            <Button onClick={() => mutation.mutate(form)} disabled={mutation.isPending}>
              {mutation.isPending ? "Saving…" : "Save"}
            </Button>
          </div>
        </CardContent>
      </Card>
    </main>
  );
}
```

Note on the form-state pattern: the editable fields live in `ProfileEditor`, mounted with `key={profile.id}`. The form state is seeded lazily from the row on mount (`useState(() => profileFormFromRow(profile))`), and the key guarantees each profile gets a fresh instance with its own seeded form — no effects, no stale snapshot, no fallback juggling.
