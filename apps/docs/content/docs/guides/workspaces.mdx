Arrange existing subshells in a workspace layout.

## Before you start

Create the subshells you want to arrange. A workspace organizes references to those sessions; it does not create a separate copy of their processes.

## Build a layout

1. Open a subshell and use its workspace or split controls to add it to a layout.
2. Add another subshell or drag an existing session into the workspace.
3. Adjust the pane layout on a wide screen.
4. Save the workspace with a name when you want to keep it.

On a small screen, the workspace presents its panes as tabs instead of side-by-side terminals.

## Drafts

Splitting a session can create a draft workspace. Drafts appear separately from saved workspaces and can be discarded without creating a named workspace.

Removing a pane from a draft with fewer than two panes deletes that draft. A subshell can still exist independently after its workspace reference is removed.

## Closing sessions

Closing a subshell permanently removes the session and its pane references from workspaces. Review [Session lifecycle](/guides/lifecycle) before confirming the action.

Changing a layout is different from changing a session's working directory or agent settings. Use [Clone and switch presets](/guides/clone) for those launch operations.
