Manage your running sessions and the settings you use to launch them.

Start with [Launch a subshell](/guides/launch) and [Use the terminal](/guides/terminal). Agents run on the selected machine, and their sessions remain available when you disconnect your browser.

## Organize work

[Workspaces](/guides/workspaces) arrange existing subshells in a layout. [Presets](/guides/presets) save agent settings and optional launch defaults. [Saved prompts](/guides/prompts) store reusable task text that you can inject into a live session.

Use [Clone and switch presets](/guides/clone) when you want a new session with related settings or need to change the preset used by an existing session.

## Work with other people

[Share a subshell](/guides/sharing) explains view and edit access. Sharing a session does not share its notification subscriptions. Configure [Notifications](/guides/notifications) and [Devices](/guides/devices) for the devices on which you want alerts.

## Finish work

Read [Session lifecycle](/guides/lifecycle) before closing a subshell. Disconnecting a browser, stopping a process, and deleting a subshell have different consequences.

For agents coordinating with each other, use [MCP and agent communication](/mcp).
