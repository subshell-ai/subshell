Save reusable task text in your prompt library.

## Create a prompt

1. Open **Prompts**.
2. Create an entry with a short description and the prompt body.
3. Keep it private unless you intend every signed-in account to read it.
4. Save it and select it from the prompt picker when launching or injecting a task.

Prompt descriptions are limited to 120 characters and bodies to 20,000 characters. The library separates your own prompts from prompts shared by other users.

## Use a prompt

An initial prompt can be assembled in a preset's prompt stack or supplied during launch. For a running session, choose **Inject prompt...** from its menu and select saved text or enter custom text.

Injection supplies input to the current process; it does not start another session or change the preset definition. Check that the agent is ready to receive a new task before submitting it.

## Sharing and agent access

> [!warning] Shared prompt text
> Sharing a prompt publishes its text to every account on the instance. Do not place secrets in a prompt you intend to share.

MCP can create, read, edit, and delete prompts belonging to its pane's owner, and read other users' shared prompts. Deleting a saved prompt has no undo.
