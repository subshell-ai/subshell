Interact with a subshell's live terminal from your browser.

## Before you start

You need edit or owner access to send input. View access allows you to watch the terminal without typing into it.

## Input and copying

Click or tap the terminal to focus it, then type commands or agent responses. The input goes to a real process on the selected node.

On touch devices, open the subshell menu and choose **Enable text copying** to select terminal text. Choose **Enable text input** to return to typing. A disconnected browser does not stop the process.

## Upload files

Drop or paste a supported file into the terminal. Uploads are limited to 25 MiB and are placed under `.subshell/uploads/` in the session's working directory. Subshell pastes the file path into the pane.

Uploaded files are not automatically removed. The upload directory is excluded from Git, but you should still review what an agent can read before supplying a file.

## Multiple viewers

A subshell has one terminal grid. Subshell sizes it to the smallest visible viewer, so opening the same terminal on a smaller screen can change its dimensions for everyone watching.

Viewer details disclose device labels and whether each viewer can type. A view-only share does not hide other attached viewers.
