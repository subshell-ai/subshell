Manage the devices you use to view sessions and receive notifications.

## Name a device

Open the profile menu at the bottom of the server dashboard's sidebar and choose **Preferences**. Under **This device**, edit **This device's name** and save it. Use a recognizable name so another viewer can distinguish your laptop, tablet, and phone. Device labels are visible to people who can view the same attached subshell.

A browser profile or installed PWA can have its own device registration. Signing in from another device does not move an agent process; it adds another way to view it.

## Manage notifications on this device

From the dashboard's profile menu, open **Preferences** and find the **Notifications** section. Use **Enable notifications on this device** to register the current browser for delivery, or **Disable on this device** to stop it receiving alerts. Manage each browser or installed PWA from that device and check its browser permission.

The subshell bell controls whether that session can send alerts to its owner's devices. See [Notifications](/guides/notifications).

## Terminal viewers

A viewer is an active attachment to a terminal. Multiple visible viewers share the pane's dimensions, which are limited by the smallest visible view.

Open a subshell's terminal and select the monitor icon with a device count in its toolbar to inspect attached viewers. Viewer details show device names, dimensions, attachment information, and whether each viewer can type. These details are disclosed to view-only recipients as well as editors.

## Sign-in on another surface

The desktop webview and system browser have separate cookie storage. **Open in browser** may therefore ask you to sign in again.
