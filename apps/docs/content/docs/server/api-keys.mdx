This page will distinguish the two bearer credentials. A subshell's token is minted at launch, scoped to its row, self-extending, and revoked the instant the subshell dies — it is how a pane talks to the plane as itself, and it appears nowhere an operator manages. A system key is the long-lived, full-access credential an admin mints under Settings → API keys for LAN tooling and scripts, plaintext shown exactly once. Both are refused on admin surfaces — machine credentials can never manage the instance — and the page will end with the rotation and deletion rules that make a lost key recoverable.
