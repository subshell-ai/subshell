This page will explain network plugins as a category: the same plugin system, pointed at reaching your server instead of driving an agent. Four ship built in — Tailscale, Headscale, NetBird, Cloudflare Tunnel — each connects the control-plane host to one network and publishes Subshell on it, so the address you used to discover through a 403 becomes trusted the moment the plugin's record earns it. The page will carry the two design rules that make third-party code safe here: a plugin DESCRIBES (argv, output parsing, naming a secret) and the host EXECUTES every effect through a bounded, audited door; and the sudo boundary is absolute — privileged steps are printed for a human, never run, because the server has no terminal to answer a password prompt.
