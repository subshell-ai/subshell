This page will cover the NetBird plugin: installing the peer (the app on macOS, the documented steps as root on Linux — printed, never run), logging in, and the one manifest difference from Tailscale and Headscale — NetBird is `publishImplicit`, so the join IS the publish: the moment the peer is up and its address recorded, that address is trusted and the publish is audited with its own row. It will carry the same boundaries as its siblings: private exposure, nothing unioned into the operator's own `TRUSTED_ORIGINS`, and leaving the network forgetting the address again.
