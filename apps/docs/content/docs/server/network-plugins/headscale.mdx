This page will cover the Headscale plugin for people who run their own tailnet controller: it drives the same `tailscale` client pointed at your `--login-server`, so joining means the login URL your Headscale serves and publishing means the address that tailnet resolves for this host. It will mirror the Tailscale page's structure — platforms (macOS, Linux), the printed-not-run privileged steps, private exposure, trust following the plugin's record — and name what differs: the control server is yours, so the vendor-docs links and the failure modes are yours too.
