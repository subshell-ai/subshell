This page will cover the instance's two self-service doors and their switches. Registration is closed by default, open only while the instance has zero users — which is how the first admin comes to exist — and an admin's explicit toggle reopens it; closing it signs nobody out. Node enrollment is on by default (any signed-in user may mint a single-use setup key and add a machine) and an admin may narrow minting to admins; neither switch revokes what is already outstanding, a distinction the page must make in its first paragraph because operators assume the opposite. Both decisions and their semantics are audited or bounded, and this page says where to see that.
