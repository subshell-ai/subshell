This page will cover the Docker deployment: `docker compose build && up`, the bind mounts (data at `~/.config/subshell-server` so SQLite, pane logs and channel keypairs survive; `~/projects` at its real path so stored paths resolve; the harness binary and its state mounted in, since it is not bundled), the port and reverse-proxy caveat, and the honest limits: a container restart ends tmux state, so running subshells die and surface as dead rows, and git-from-panes needs the SSH/gitconfig mounts the compose file sketches. It will link the compose file as the source of truth rather than restating it.
