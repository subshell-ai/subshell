This page will document configuration: `~/.config/subshell-server/config.env` (0600), the precedence ladder every value follows — process env, then config.env, then `.env`, then built-in defaults — and the split of who writes what: the `subshell-server configure` CLI and the dashboard's Settings → Service page both write the same five keys through one shared validator, a hand-edit is yours, and a key that the environment already sets is refused by the writers rather than masked. The full variable table lives on the Environment Variables reference page; this page carries the mental model and the traps (an env var shadowing your file edit; changing `APP_BASE_URL` moving the passkey rpID).
