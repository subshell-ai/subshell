This page will cover keeping the control plane running without a terminal held open: `subshell-server service install` writing a systemd user unit (Linux) or launchd agent (macOS), the enable/disable pair that arms login start without touching the running process, and start/stop/restart from the CLI. It will teach the one diagnostic that saves afternoons — `service status` reporting whether a restart or stop would take the live tmux panes down with the server (a definition written before the pane-safety fix does), which is why `restart` refuses without `--force` and bare `systemctl` says nothing. Plus Linux linger, without which a user service dies at logout.
