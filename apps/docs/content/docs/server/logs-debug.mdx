This page will cover the server's own logging: one JSON-lines file at `<data dir>/logs/server.log`, 0600 in a 0700 directory, capped at 200 KB and replaced when full — bounded by size, never swept, unlike the pane logs swept by age. It will cover debug mode (an instance setting applied live from the dashboard, audited, request paths visible only while it is on, `SUBSHELL_DEBUG_LOGGING=1` forcing it from the environment), reading the log over HTTP as an admin, and the separate world of pane transcripts — each subshell's screen output on disk, the most sensitive thing the app writes. Open question to settle while writing: the exact boundary the page draws between `status`, this file, and the service manager's log.
