This page will cover backups: `subshell-server backup` snapshots the SQLite database (the same automatic snapshot every server upgrade takes before swapping binaries), the retention of the automatic ones (five kept, `SUBSHELL_DB_BACKUPS_KEEP`), and exactly what a snapshot covers — accounts, subshells, shares, settings, audit — and what it does not: pane log files on disk, plugin secrets (those are 0600 files outside the database, so a restore needs them re-entered), and enrolled nodes' keys. The rule to state first: the database is the instance's memory; if you only back up one thing, it is this, and it is what makes a failed update a revert instead of a rebuild.
