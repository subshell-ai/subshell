This page will cover installing the control plane on a headless Linux machine: the `install-server.sh` one-liner (platform detection, digest-verified download to `~/.local/bin/subshell-server`, then `init`), answering `init`'s single question about background service and login start, the variables that pre-answer everything (`SUBSHELL_SERVER_PORT`, `_HOST`, `_BASE_URL`, `_TRUSTED_ORIGINS`, `SUBSHELL_NO_SERVICE`), and the prompt to open the printed `/setup` URL before anyone else on the network does. It will end where the box takes over from the terminal: the first-boot `status` read, and browsing to the address you configured.
