This page will untangle the three addresses people conflate: what the server binds (`HOST`, default all interfaces), what it calls itself (`APP_BASE_URL`, also the passkey rpID), and what browsers may use (the trusted-origin allowlist, derived live from the instance's own addresses, the operator's extras, and network plugins' published records — never from the request's own Host, which is the DNS-rebinding hole the list closes). It will diagnose the 403 "Invalid origin" sign-in failure by name and fix it with the right lever, and position mesh networks (the Network Plugins section) as the way to make a private address trustworthy.
