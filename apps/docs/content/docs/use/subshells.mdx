This page is the core concept in one place: a subshell is a real CLI agent (or plain shell) running in a tmux pane on some machine, kept alive by the server rather than by your browser. It will cover launching one (agent, folder, optional name and preset), watching it from any device after closing yours, typing into it, the restart that keeps the same row and rotates its credentials, terminate and delete and how they differ, and what the status indicators mean — including why an offline node says "node unreachable" instead of "crashed". Written for anyone who has launched one and wondered where it goes when the tab closes.
