This page will explain how an agent flags you when it is done or stuck: a harness reports attention through the subshell's own credential, and pushes go only to the subshell's owner's devices — sharing widens who can watch, never who gets pushed. It will cover the two switches (the per-user master toggle and the per-subshell bell), delivery to the native mobile companion, and the desktop app's own notifications.
