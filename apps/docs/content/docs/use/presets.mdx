This page will cover presets: optional saved launch settings for a harness — env vars, CLI flags, settings JSON, and config-source isolation so two subshells of the same agent can keep separate state. It will show where they are edited, how a launch uses one (a launch needs only an agent and a folder; a preset is always optional), the preset env vars merging on top of the curated environment, and that a fresh instance has none and every preset is deletable. For hermes and pi, the preset editor is also where the one-time MCP registration command is shown.
