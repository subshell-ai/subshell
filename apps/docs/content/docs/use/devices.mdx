This page will cover presence and devices: every browser attached to a subshell announces itself with a chosen device name (defaulted from the browser — "Safari on iPad"), and everyone attached sees that list, which is why a shared pane tells you who else is watching. It will explain what a device's entry means — which grid it displays, when it attached, whether it is being rendered, whether it may type — and how the server turns those facts into one answer: the pane's size, always the smallest visible viewer that can type. The Devices list is where "why does this look tiny on my desktop" gets its explanation.
