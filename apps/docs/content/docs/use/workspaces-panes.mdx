This page will explain workspaces: per-user saved arrangements of subshell panes, tiled side by side on a wide screen via dockview, split from any pane's menu or by dragging a subshell onto half of another. It will cover what the layout stores and when it writes (below 1024px it renders tabs and never saves, so a phone visit cannot flatten a desktop arrangement), moving and closing panes without killing their subshells, and the one-grid rule behind all of it — a tmux pane has a single size, so a shared pane is sized to the smallest visible viewer. That last part answers the classic "why is my terminal 80 columns" and links to the sharing and devices pages.
