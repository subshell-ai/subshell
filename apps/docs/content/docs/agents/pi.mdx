This page will cover running pi as a subshell: detection of the `pi` binary (`PI_PATH` overrides, known install location under `~/.bun/bin`), and the same one-time MCP registration as hermes — pi has no per-subshell config, so the preset editor shows the registration command to run once, after which each subshell authenticates with its own injected credentials. Written for someone who chose pi for its minimalism and wants to know what Subshell adds to it.
