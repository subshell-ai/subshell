This page will cover the Terminal plugin: a subshell that drives no agent CLI, just your shell (`SHELL`, falling back to `bash`) in a tmux pane. It is the one built-in with nothing to detect or install, which is what makes a brand-new machine launchable before you have put an agent CLI on it — and a perfectly good way to use Subshell as a browser-and-phone tmux terminal with everything else attached: sharing, workspaces, pane logs, nodes. It will be short, and that is the point.
