This page will cover installing plugins beyond the built-ins: the control plane's single plugin store (one install arms every node), the Settings → Plugins admin surface, installing from a registry by URL — the default being npm's, with the harness plugins published as `@subshell-ai/plugin-<id>` — and from a local archive. It must state the trust decision honestly: installing a plugin runs third-party code in the control-plane process, which is why it is admin-only, and integrity proves the bytes match the hash the same registry published — over an http mirror that assurance is your network's, not npm's.
