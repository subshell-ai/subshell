Run Claude Code as a Subshell agent.

## Before you start

Install `claude` using the [vendor instructions](https://code.claude.com/docs/en/setup) and authenticate it under the execution account. Enable its harness plugin on the instance and confirm detection on the target node.

## Launch

1. Open the launch dialog and select **Claude Code**.
2. Select a preset or configure the supported launch settings.
3. Choose the target node and an existing project directory.
4. Launch and confirm that the CLI opens normally.

The plugin detects `claude` through PATH and its known locations. `CLAUDE_PATH` can identify the binary explicitly in the execution environment.

## MCP and session behavior

Automatic configuration supplies a per-subshell MCP file and attention hooks. Claude Code is the built-in harness that declares conversation resumption and attention reporting. Restart can resume a surviving transcript; clearing or forking a conversation can change its session identity.

Subshell runs the real CLI rather than proxying its provider API. Provider configuration, usage limits, and CLI-specific permissions remain the agent's own settings.
