This page will cover running Claude Code as a subshell: how Subshell finds the `claude` binary (PATH plus the known install locations, overridable with `CLAUDE_PATH`), what the launch looks like, and that the `subshell mcp` server is wired in automatically per subshell via a generated `--mcp-config` file — so channels and agent-to-agent tools work from the first prompt with nothing to register. It will note the one host environment variable the plugin carries through (`CLAUDE_CONFIG_DIR`), where to install the CLI if detection finds nothing, and that the hooks a session uses are handed the host-resolved command line rather than a guessed binary.
