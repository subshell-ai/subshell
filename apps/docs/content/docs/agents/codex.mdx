Run Codex as a Subshell agent.

## Before you start

Install `codex` using the [vendor instructions](https://learn.chatgpt.com/docs/codex/cli) and authenticate it under the execution account. Ask an administrator to enable the harness under **Server Settings** → **Plugins** in the server dashboard's sidebar. Follow [Install an agent CLI](/agents/install-cli) to confirm detection on the target node.

## Launch

1. In the server dashboard's sidebar, choose **Subshells**, select **New subshell**, and choose **Codex**.
2. Select a preset or configure the supported launch settings.
3. Choose the target node and an existing project directory.
4. Launch and confirm that the CLI opens normally.

The plugin detects `codex` through PATH and its known locations. `CODEX_PATH` can identify the binary explicitly in the execution environment. Before changing that override, see [Files and paths](/reference/paths) for configuration locations and service-environment guidance.

## MCP and session behavior

Subshell supplies MCP configuration through per-launch CLI settings. You do not need to register the Subshell MCP server globally for this harness. The built-in plugin declares MCP and settings capabilities; it does not declare automatic conversation resumption or attention hooks.

Subshell runs the real CLI rather than proxying its provider API. Provider configuration, usage limits, and CLI-specific permissions remain the agent's own settings.
