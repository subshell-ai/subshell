This page will cover installing an agent CLI from inside Subshell: the setup screen's install button, which runs the built-in plugin manifest's install command as the server's user — admin only, audited, bounded output and a deadline. It will be clear about the boundary: this installs on the control-plane host, and it is admin work on that machine, not fleet provisioning; getting a CLI onto every node is a matter of logging into those machines (or packaging them), and this page should say that plainly. It will show the command each built-in runs and link the vendor docs for the manual path.
