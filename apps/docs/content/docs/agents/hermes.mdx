This page will cover running Hermes as a subshell: detection of the `hermes` binary (`HERMES_PATH` overrides), and the one difference from claude-code, opencode and codex — Hermes has no per-subshell config file, so the MCP server registers once per install: the preset editor shows a one-time registration command, run it and every later subshell authenticates through its own baked-in credentials. It will show that command's home, what "already registered" looks like, and where to install the CLI if detection finds nothing.
