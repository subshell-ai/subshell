This page will cover running OpenCode as a subshell: detection of the `opencode` binary (`OPENCODE_PATH` overrides, known install location under `~/.opencode/bin`), and its automatic per-subshell MCP wiring — a merged config layer pointed at by `OPENCODE_CONFIG`, so Subshell's MCP entry is added without touching your own opencode config. It will show where that layer is built and what a launch looks like on the plane and on a node.
