This page will trace one launch end to end for the curious operator and the aspiring contributor: the browser's request reaching the control plane, the plane building the harness's command line, tmux spawning the pane on the machine that will run it (this host or an enrolled node), the pane's output streaming back over the same WebSocket whether it is local or remote, and the per-subshell credentials that let the agent talk back. It stays at the "what talks to what" level — the security model page covers trust, and the node protocol reference covers the wire.
