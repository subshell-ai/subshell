This page will position Subshell for someone choosing how to run coding agents: versus driving an agent CLI directly in a terminal, versus a plain tmux-over-SSH setup, versus hosted "agents in the cloud" products, and versus terminal multiplexer companions like web front-ends for tmux. The honest axes are durability (panes survive your laptop closing), reach (any device on your own network), orchestration (agents messaging each other over encrypted channels), and what each option does with your credentials. The comparison itself is open editorial work: the repository describes what Subshell is and never enumerates its alternatives, so this page needs a candidate list and fairness pass decided by the maintainers before it can be written.
