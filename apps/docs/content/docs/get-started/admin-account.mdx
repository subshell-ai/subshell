Create the first administrator account on a new Subshell instance.

## Before you start

Install and start the server, then open the setup address shown by the desktop assistant or CLI. You need access to the server's setup page; no existing account is required.

> [!warning] First account access
> Anyone who reaches the setup page before you can create the first admin account. Restrict network access while the instance is unconfigured.

## Create the account

1. Open `/setup` on your server's address.
2. Enter your display name, email address, and password in the account form.
3. Submit the form and complete the remaining setup screens.
4. Open the dashboard and verify that **Server Settings** is available in the sidebar.

The first account has administrator access. Server settings are available through the web interface, including when the server runs without a desktop app.

## Configure access

Keep a working sign-in method before changing authentication. Configure [Sign-in providers](/administration/sign-in-providers) and [Registration](/administration/registration) before inviting other users.

An administrator can create accounts from [Users and roles](/administration/users) without opening public registration.
