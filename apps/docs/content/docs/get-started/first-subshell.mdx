Launch a Terminal subshell and reconnect to the same running session.

## Before you start

Sign in to a configured server. The target machine needs tmux and an available shell. Terminal does not require an agent CLI or a provider account.

## Launch the session

1. Open the dashboard's launch dialog.
2. Choose **Terminal** in the agent field.
3. Choose a launchable node. The server's host is named **Server** by default, but an administrator can rename it.
4. Select an existing working directory on that machine.
5. Launch the subshell and open its terminal.

Run a harmless command to verify input and output:

```bash
pwd
```

The returned path is on the selected machine. A path on your laptop has no meaning on a different node unless that directory also exists there.

## Reconnect

Close the browser tab, open the server again, and select the subshell from the sidebar. The session continues while its machine and process remain running.

> [!warning] Closing a session
> Closing a browser tab only disconnects your view. The subshell's **Close** action in this version stops the process and deletes its row and captured history.
