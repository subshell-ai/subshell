This page will walk the browser-side half of day one: creating the admin account in the setup wizard, adding or detecting an agent CLI (the wizard's last screen pre-fills the agent it found, with Terminal as the fallback that needs nothing installed), choosing a working folder in the in-app file browser, and launching. It will show what the terminal page is — a live tmux pane you can detach from and reattach to — and end with the terminate button and what it does. A launch needs only an agent and a folder: no preset exists on a fresh instance, and none is needed.
