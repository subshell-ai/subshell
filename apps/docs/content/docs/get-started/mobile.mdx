This page will cover running Subshell on a phone or tablet: opening the same URL your desktop uses (which means getting origins and `APP_BASE_URL` right first — the networking page owns that), the mobile web shell with its drawer navigation, tab-style workspaces and terminal key bar, Add to Home Screen for a chrome-free app on iOS, and the native Subshell for Mobile companion for what a web page cannot do — push notifications, badge counts, and lock-screen actions with a credential kept in the Keychain. It will be honest about the split: the browser is the terminal; the companion is the bell.
