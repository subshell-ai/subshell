This page will be the shortest working path to your first subshell: install or start the control plane, open the setup wizard and create the admin account, make sure tmux and at least one agent CLI are present, launch a subshell from a project folder, and open it from a second device. Each step links to its full page for people who want the options; this page itself will not exceed one screenful per step. It is written for the operator who wants to see the thing work before deciding whether to read anything else.
