Set up Subshell Server and launch a terminal that remains available when you close the browser.

## Before you start

Use a supported Linux or macOS machine with permission to install applications. The machine must remain running while you use its server. You do not need a coding agent account for this first session.

## Set up the server

1. Open [Subshell downloads](https://subshell.sh) and download **Subshell Server** for your operating system. See [Install Subshell Server](/install/desktop-server) for setup details.
2. Open the app and follow its setup assistant. It prepares the bundled server and checks for tmux.
3. Open the setup page when the server is ready.
4. [Create the first admin account](/get-started/admin-account).

The app opens the dashboard when the server is running. The dashboard is the same web interface you can open in a browser.

> [!warning] Protect first setup
> Anyone who can reach an unconfigured instance can create its first admin account. Keep the server on a trusted network until you finish setup.

## Launch a terminal

Follow [Your first subshell](/get-started/first-subshell), choosing **Terminal** as the agent. After confirming that the session works, [install an agent CLI](/agents/install-cli) on the machine where your agent will run.

## Other installation methods

[Installation](/install) covers CLI, Docker, and Proxmox deployment. To resume this session elsewhere, follow [Connect from another device](/get-started/another-device).
