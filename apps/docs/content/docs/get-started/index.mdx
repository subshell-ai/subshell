Five steps, each linking to its full page.

## Prerequisites

You need one machine you control (Linux x86-64/arm64 or macOS on Apple silicon or Intel) and tmux. An agent CLI helps but is not required: the plain Terminal harness needs nothing installed, so you can start with zero.

## 1. Install and start the control plane

On the machine that will run the server, run:

```bash
curl -fsSL https://raw.githubusercontent.com/subshell-ai/subshell/main/install-server.sh | bash
```

The script downloads the `subshell-server` binary for your platform from the newest GitHub release. It verifies the published `.sha256` digest before making the file executable, installs the binary to `~/.local/bin/subshell-server`, and runs `subshell-server init`. The install asks one question that decides your setup: whether to run the server in the background and start it at login. The default is yes, and you can accept every other prompt with Enter. If you prefer a window and a button to a terminal, use the [Subshell Server desktop app](/get-started/install-server#subshell-server-desktop-app) instead.

The command ends by printing the address:

```
Open http://localhost:3080/setup in a browser to create the admin account.
```

## 2. Create the admin account

Open the `/setup` URL now. The setup endpoints are public until the first account exists, and that is what lets you create it. On a LAN this is a race: whoever walks through the page first becomes the admin. The wizard's first screen is **Create Your Account**. The screen after it, **Connect a Network**, is optional, and skipping costs nothing; every choice there is reachable again under Settings, and [Networking & Addresses](/server/networking) explains them. [Your First Subshell](/get-started/first-subshell) covers the whole wizard.

## 3. Add tmux and an agent

The **Install tmux** screen comes before the agent list, because every pane on the machine runs inside tmux and nothing launches without it. The screen gates: **Continue** stays disabled until the check finds tmux, so on a machine that already has it this costs one press. Where the install command needs no password, such as Homebrew on macOS, the screen offers an **Install** button. Where it would need `sudo`, the server has no terminal to answer the prompt, so the screen prints the command for you to run instead.

After tmux, the **Add an Agent** screen lists the agent CLIs it can see on the server's machine (Claude Code, Codex, OpenCode, Hermes Agent, pi). A missing agent CLI works the same way: **Install** runs the vendor's own install command on this machine. The **Terminal** harness (a plain shell pane) is always available with nothing installed. See [Agents](/agents) and [Installing Agent CLIs](/agents/installing-agent-clis).

## 4. Launch your first subshell

The wizard's last screen is a launch form already filled in: the server's own machine (its node is named "Server" by default), a detected agent, and a starting directory. Pick a project folder and press **Start**. No preset exists on a fresh instance, and none is needed: a launch needs only an agent and a folder. The page that opens is the live pane. Type into it, close the tab, and reopen it from anywhere; the agent keeps running.

## 5. Open it from a second device

On a laptop or tablet, browse to an address the server accepts sign-ins from and sign in. The loopback URL from step 1 is only this machine's own spelling; the wizard's **Connect a Network** screen or the Server settings add the LAN or mesh addresses. The page shows the same live pane, yours to type into.

On a phone, open the **Subshell for Mobile** dialog in the sidebar. It offers the addresses this server accepts sign-ins from, with a QR code, and installing to the Home Screen makes it a standalone app with notifications. [Mobile and Tablet](/get-started/mobile) covers the split, and [Networking & Addresses](/server/networking) explains what makes an address reachable, including the mesh options under [Server](/server).

Once this works and you want another machine running agents, that is what [Nodes](/nodes) is for.
