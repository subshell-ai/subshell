This page will cover system keys as an operator practice: minted by an admin under Settings → API keys, owned by the `system` service user, full-access bearer credentials whose plaintext is shown exactly once (only a hash survives), disabled or deleted into instant revocation. It will give the guidance the mechanism cannot enforce — these keys hold no ceiling, so scope by minting one per purpose and keeping the break-glass one in a vault, not in CI — and the refusal that bounds their blast radius: they can use the API, never manage the instance, because every admin surface rejects bearer credentials.
