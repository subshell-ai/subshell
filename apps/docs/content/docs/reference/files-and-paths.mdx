This page will map the filesystem: the server's config home (`~/.config/subshell-server/config.env`, 0600 in a 0700 dir), its data dir (SQLite, `logs/server.log`, per-subshell pane logs, channel keypairs, `node-signing.json`, VAPID keys, the plugin store and plugin-state secrets, database backups, node artifacts); and the agent's side (`~/.config/subshell/config.json` — the node key's only home — and its data dir with identity, allowlist, maintenance mirror, update markers, pane logs and MCP configs). Every entry with its permissions and one line on why they are set that way, since several of these files are credentials.
