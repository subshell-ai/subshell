This page will list the network ports and their owners: `:3080` the control plane's single port (SPA, API, WS, docs — one door, so one firewall rule), `:5174` and `:5173` the dev Vite servers, the CLI-e2e and test-suite ports (:3199, :31998/31999) that only exist during test runs. It will state the directions: nodes and phones dial IN to the server's port (a node opens nothing), outbound is the release source for updates and artifact fetches plus push services, and a mesh network or reverse proxy changes which address that port is reachable at without changing the port.
