This page will define the vocabulary, and in this product vocabulary is load-bearing: **server** means the control plane (API, database, its SPA) and never a machine that runs agents; **node** means a machine running agents via the `subshell` daemon; **client** means a person's interface to a control plane — web, mobile, desktop. Around those three it will define subshell, pane, workspace, preset, channel, harness, plugin (agent-harness / terminal / network), setup key, node key, system key, and the display names — "Subshell Server", "Subshell Client", and the control-plane host's node row, which is named by an admin and defaults to "Server". Each entry gets one paragraph and a link to the page that goes deep.
