This page will be the reference for the agent binary: `setup` (the whole enrollment in one command, including the service offer), `enroll` as the primitive, `configure --server` for repointing an enrolled node, `run`, the `service` family, `maintenance on/off/status`, `status` (with `--probe`), `update` with its transaction flags and `--rollback`, `version`/`license`, and the internal `mcp`/`report` verbs. It will state the exit-code contract (0 ok, 1 runtime failure, 2 usage) that makes the CLI scriptable, and cross-link the repoint-versus-re-enroll distinction, because those two commands look alike and are not.
