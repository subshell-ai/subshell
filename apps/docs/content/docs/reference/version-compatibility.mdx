---

This page will explain the two gates a node must clear to be useful: the node protocol version (a wire number both sides must agree on, checked at connect) and the minimum agent version the control plane will accept, both defined in the shared protocol package; and the `release-manifest.json` every published release carries (component, version, protocol number, minimum agent, commit sha) so a control plane can answer "is this node release compatible with me" without downloading a binary. It will tell operators what happens at a mismatch — a refused agent says so by name — and the practical rule: keep desktop and CLI cuts together (`app=all`) when a change crosses the wire.
