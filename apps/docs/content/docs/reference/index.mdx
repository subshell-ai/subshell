Look up the interfaces and configuration values used by Subshell.

## Commands and configuration

- [Server CLI](/reference/server-cli) describes the `subshell-server` command.
- [Node CLI](/reference/node-cli) describes the `subshell` command.
- [Environment variables](/reference/environment) separates server configuration from pane identity.
- [Files and paths](/reference/paths) identifies instance, node, and agent storage.
- [Ports](/reference/ports) describes listener and connection direction.

## Integration interfaces

[MCP tool reference](/mcp/tools) is the authoritative documentation page for agent tools. [API conventions](/reference/api) explains authentication and errors; the running server's `/docs` provides its generated endpoint schemas.

[Node protocol](/reference/node-protocol) explains signed commands and connection behavior. [Version compatibility](/reference/versions) describes release versions and exact protocol matching.

## Terminology

Use [Glossary](/reference/glossary) for product terms. The server, node, and client names describe distinct roles even when one physical machine performs more than one role.

## Choosing a guide

Reference pages are for lookup. For procedures, use [Installation](/install), [Server administration](/administration), or [Manage nodes](/nodes).
