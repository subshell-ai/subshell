This page will walk enrollment: Settings → Nodes → Add node renders a one-liner carrying a single-use setup key (24 hours, hashed at rest, revocable); you run it on the target machine, where it checks for tmux, downloads the matching `subshell` binary, verifies the published digest before the first `chmod +x`, enrols, and offers to install the background service. It will cover the loopback trap — the server URL is baked into the command, so `APP_BASE_URL` must name an address the node can actually reach — the `subshell setup` verb for machines that already have the binary, and Linux linger for keeping the agent alive past logout.
