This page will cover the node half of updates: `subshell update --check` to see what the release source offers, the update that downloads the newer agent binary and restarts into it, and the transaction that makes it safe — the old binary is kept as `.previous`, the new one must boot clean to keep, and a failed boot puts the old binary back on its own. It will cover the same update driven from the node's page (an edit-grantee act: the URL and digest ride inside the signed command) and the honest risk class: an update replaces an executable from the release source, so an empty `SUBSHELL_RELEASE_URL` (air-gapped) disables the path entirely.
