This page defines the word and its cost. A node is a machine running the `subshell` agent daemon; it holds no UI of its own, receives signed commands from the control plane, and runs panes under its OS user — the browser cannot tell a remote pane from a local one because they stream over the same WebSocket. The page will state the delegation plainly before the how-to pages: registering a node hands this control plane the right to run arbitrary commands on that machine as that user, the signing key on the plane rules every enrolled node, and node traffic is authenticated but expected to ride your VPN or Tailscale.
