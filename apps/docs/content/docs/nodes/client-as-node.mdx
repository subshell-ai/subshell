This page will cover the desktop path to running agents on your laptop: Subshell Client carries a second window ("This machine…") that registers this machine as a node and manages the agent — paste a setup key and it enrolls, installs the agent as a background service, and shows you its state. It will say who needs this (someone who watches subshells from the same machine they want to launch on — which is most people) and who does not (a machine you only watch from never opens that window). It will also carry the warning that enrolling twice is destructive: the second enroll overwrites the config, mints a second node row, and discards the first node key.
