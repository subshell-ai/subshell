This page will cover the directory allowlist: an owner-only setting that limits which directories subshells can launch in on a given machine. It will be exact about the semantics — empty means unrestricted, never deny-everything — because that is the rule an operator must not invert in their head; the owner-only gate and why an edit grantee deliberately cannot widen the list (any share already lets them launch, so widening rights would dissolve the restriction); and the enforcement being doubled, on the control plane against the resolved path and again on the node against its pushed copy of the list, because signing proves who, not whether.
