Report issues and find the release notes for your installed component.

## Report a problem

Use the public [issue tracker](https://github.com/subshell-ai/subshell/issues). Include the component versions, operating system, installation method, exact error, and the steps needed to reproduce it.

State whether the problem occurs in a browser, the server desktop app, the client desktop app, or a node command. Include the relevant configuration names without their secret values.

> [!warning] Public reports
> Issue reports are public. Redact bearer keys, node setup keys, passwords, provider secrets, private project output, and identifying host information as appropriate.

## Security reports

Do not publish an exploitable security issue in the public tracker. Follow the project's [security policy](https://github.com/subshell-ai/subshell/blob/main/SECURITY.md), which provides the private reporting contact.


## Release notes

Use [Subshell downloads](https://subshell.sh) for installation downloads. [GitHub Releases](https://github.com/subshell-ai/subshell/releases) carries component release notes. Match `cli-server`, `cli-node`, `desktop-server`, or `desktop-client` to the component you installed.

The newest release overall is not necessarily the newest release for that component. Desktop bundles include their corresponding CLI.
