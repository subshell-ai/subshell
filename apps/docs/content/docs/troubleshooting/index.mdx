Diagnose a Subshell problem from its observable symptoms.

## Start with diagnostics

On a server host:

```bash
subshell-server status
subshell-server service status
```

On an enrolled node:

```bash
subshell status
subshell service status
```

Capture the component version, exact error, and whether the problem occurs in a browser, desktop window, or host command. Do not include credentials in your report.
