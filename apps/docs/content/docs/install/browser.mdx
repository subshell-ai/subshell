Use Subshell through your browser or install its web interface as a standalone web app.

## Before you start

Open a server address reachable from your device. Secure contexts are required for browser features such as service workers, passkeys, and web push; use HTTPS for remote access.

## Open in a browser

1. Open the server address.
2. Sign in with your account.
3. Select a subshell or workspace.

On phones and tablets, the layout adapts to the smaller screen. Workspaces use tabs where there is not room for side-by-side panes.

## Install the web app

On iPhone or iPad, open the server in Safari and choose **Add to Home Screen** from the share menu. Open the installed web app before requesting notification permission.

On browsers that support installation, use the browser's install action. Installation support and wording vary by browser.

The server's device-linking dialog can provide a QR code for a reachable address. The QR link is a navigation aid; it does not sign you in or grant access.

## Notifications

Enable notifications for this device and for each subshell you want to hear from. Notifications are sent to the session owner, not everyone who can view a shared session.
