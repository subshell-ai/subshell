Develop Subshell and its plugin integrations from the public repository.

## Contribute

[Contribute to Subshell](/developers/contribute) covers the workspace, local development, tests, and contribution licensing. [Write documentation](/developers/documentation) describes the MDX authoring and verification contract.

The repository is public and dual-licensed. Server implementations are AGPL-3.0-only; the rest of the project is Apache-2.0, with an explicit additional permission for API type declarations.

## Build a plugin

[Plugin API](/developers/plugin-api) explains the factory and manifest contract. Choose [Build a harness plugin](/developers/harness-plugin) for an agent CLI or [Build a network plugin](/developers/network-plugin) for a network connection.

[Publish a plugin](/developers/publish-plugin) covers bundled output and administrator installation. Plugins must work when loaded by a compiled binary without a neighboring `node_modules` directory.

## Integration reference

[Build an API integration](/automation/integrations) covers schemas, TypeScript clients, credential boundaries, errors, retries, and WebSocket access.

For agents calling the product, use [MCP tool reference](/mcp/tools). For external scripts, use [REST API](/automation/rest-api). The generated OpenAPI page on a running server supplies endpoint schemas.
