This page will explain how releases are numbered and where each set of notes lives, because there are four of them: the control plane, the node agent, and the two desktop apps share this repository but version independently under `server-v`, `node-v`, `desktop-server-v` and `desktop-client-v` tags. Each GitHub Release carries that component's changelog section as its body, and the in-repo `CHANGELOG.md` per app is generated from changesets, not hand-written. The page will link the releases page and the four changelogs, and explain the update channels from the product's side — what the desktop apps' updater reads, what `update --check` consults. It will stay a map rather than a mirror: a second copy of release prose here is the one that goes stale.
