Understand how Subshell connects your interfaces to agent processes.

## Components

A server is the control plane, a node is an execution machine, and a client is your interface. [Architecture](/concepts/architecture) shows how these components communicate.

The server serves the web interface and manages the instance database. A node runs real CLI processes in tmux, including when that execution machine is the server's own host.

## Sessions

[Session lifecycle](/guides/lifecycle) separates a live process from its stored row and browser connections. An offline node is not proof that its process stopped.

Agent state and provider credentials belong to the CLI and execution account. Subshell does not replace an agent's provider login or sandbox its filesystem access.
