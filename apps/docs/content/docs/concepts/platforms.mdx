Choose a supported execution platform and client interface.

## Execution binaries

The server installer supports published binaries for Linux x86-64, Linux arm64, macOS Intel, and macOS Apple silicon. Node installation uses the corresponding published node target.

Agents need tmux and a supported shell environment. A server installed as a release binary does not need Bun or a checkout to serve its web interface.

Use the assets actually present in the selected release rather than assuming an older release includes every current target.

## Desktop applications

Subshell Server wraps the control plane; Subshell Client wraps access to a server and local node management. Choose a matching desktop release for your platform.

Linux desktop apps need a graphical environment and their native WebKitGTK dependencies. A headless Linux deployment should use the CLI or container path.

Windows is not a published server or node execution target in the installation scripts. Browser access is independent of those execution targets.

## Browser access

You can use the web interface from desktops, phones, and tablets that can reach the server. Browser feature support varies; secure contexts matter for passkeys, installation, and web push.

Network plugin support is separately declared per plugin. An installed server does not imply every network integration is available on its OS.
