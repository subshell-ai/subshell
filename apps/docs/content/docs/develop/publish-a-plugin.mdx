This page will take a finished plugin to installed: the package conventions (`@subshell-ai/plugin-<id>` is the house style; the `subshell` key carries identity so listing a plugin needs no code execution), publishing to a registry, and the install path an operator follows — registry install by spec or a local archive, into the control plane's one store where it arms every node. It will state the trust model from the author's side: your code runs in the control-plane process with the server's privileges and no sandbox, which is exactly why installs are admin-gated and audited; and integrity proves bytes-match-hash against the same registry that published them — run your registry over http and that assurance is your network's, not npm's.
