This page will be the walkthrough for a `type: "network"` plugin: the manifest's network block (platform support is data, exposure is declared, privileged steps are listed for a human to run), the interface it implements — join, publish, unpublish, status, settings fields, named secrets — and the rule that governs every line: a network plugin DESCRIBES and the host EXECUTES. It returns argv and parses output; it never spawns, never writes a file, never touches config.env, and its secrets are hydrated by the host, never read back. The page will show why that discipline exists (an install runs third-party code in the process holding every node's signing key) and walk a built-in network plugin as the reference implementation.
