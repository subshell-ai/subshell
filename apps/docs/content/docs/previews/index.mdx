Web previews & screens lets you check a website or graphical app alongside the agent building it.

## Prerequisites

<span id="enable-web-previews-and-displays-on-the-machine" />

Set up the machine that runs your subshell. You can view its previews from a
browser on another computer, phone, or tablet, or from Subshell Client. The
viewing device doesn't need the node daemon or display software of its own.

- **A connected node:** follow [Desktop node setup](/nodes/desktop) for a machine
  with a desktop environment, or [Enroll a node with the CLI](/nodes/enroll)
  for a headless machine. You can also use the server's built-in node.
- **Node owner opt-in:** follow [Preview prerequisites and setup](/previews/setup)
  to enable web previews, virtual displays, or both. An administrator manages
  the server's built-in node.
- **Display dependencies:** follow [Linux virtual displays](/previews/linux) or
  [macOS virtual displays](/previews/macos) on the node that runs the subshell.
  Web app previews don't require a virtual display.

## Arrange and refresh views

Each app, browser watch, or display opens in its own workspace tab. On desktop,
a new preview splits to the right of its terminal. Reopening the same view
focuses its existing tab. Each open preview also appears beneath its subshell
in the sidebar.

Drag preview tabs to keep several apps or screens visible together. Closing a
preview leaves its subshell and other previews running. Hidden previews release
their viewer connections and reopen when you select them again.

The viewer toolbar has refresh and a **More view actions** menu:

- **Maximize pane** enlarges that workspace pane. **Restore pane** appears
  directly in the toolbar while maximized.
- **Full screen** uses your browser's fullscreen mode. **Exit full screen**
  appears directly in the toolbar while active.
- **Open in browser tab** opens a web preview in a separate browser tab.
- **Close view** closes the current viewer.

Use the subshell header's Web previews & screens icon to open another view.
On a phone, previews use the workspace's tab strip without changing your desktop
split layout. From the standalone subshell page, the header icon takes you into
the workspace and opens the picker there.
