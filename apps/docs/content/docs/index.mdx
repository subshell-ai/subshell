Subshell runs real CLI coding agents (Claude Code, OpenCode, Codex, Hermes, pi) in live terminal panes on machines you own. You start an agent from the browser, close the tab, and the pane keeps working; open any other device and you are back at the same session, typing. When the agent needs a decision, Subshell sends you a push. The whole thing is one binary you host yourself.

## Three words

Subshell uses three words with exactly one meaning each, and every page here follows them:

- A **server** is the control plane: the API, its database, and the web UI it serves. It is not a machine that runs agents.
- A **node** is a machine that runs agents: any host enrolled to execute panes for the control plane.
- A **client** is a person's interface to a control plane: the web UI, the desktop app, the mobile app.

One machine can hold all three roles at once; the server host running its own agents is the normal case. [What Subshell is](/concepts) explains the ideas behind the product, and the [Security model](/concepts/security-model) states plainly what the trusted-network posture defends and what it does not.
