Subshell runs real CLI coding agents (Claude Code, OpenCode, Codex, Hermes, pi) in tmux-backed terminal panes on machines you own. You can start an agent from the browser, close the tab, and pick up the same live pane you can type into from any other device, on a laptop, a tablet, or a phone. When an agent needs a decision, Subshell sends you a push. The panes keep running when you close your laptop. You host the server yourself as a single binary, so no one else's cloud sits between you and your agents.

## Three words

Subshell uses three words with exactly one meaning each, and all of these docs follow them:

- A **server** is the control plane: the API, its database, and the web UI it serves. It is not a machine that runs agents.
- A **node** is a machine that runs agents: any host enrolled to execute panes on the control plane's behalf.
- A **client** is a person's interface to a control plane: the web UI, the desktop app, and the mobile app.

One machine can hold all three roles at once. The server host running its own agents is the normal case, and these docs say so every time. [What is Subshell](/about) explains the concepts, and the [Quickstart](/get-started) is one page.
