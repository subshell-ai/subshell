A sidebar group headed "node you can't see" no longer spells that machine's full id on hover. The id was a leftover reveal from the retired node pill, meant for telling machines apart; for a node the registry has already refused to name it discloses nothing a reader can act on (ruling 2026-10-10). A cold registry still reveals the full id under a short one, because there the machine is the reader's own, merely not loaded yet.
