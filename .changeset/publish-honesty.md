The publish section speaks each network's truth, and a base-URL move is confirmed

NetBird has no vendor-side publish — joining already makes its addresses
answer; the press only records them as how this server is reached. Its joined
card now says exactly that under an "Other devices" heading, instead of
borrowing the Serve/tunnel networks' "Publish" framing for a concept its
vendor does not have.

And the "Set as this server's base URL" checkbox on one plugin can now silently
steal the base URL from another plugin's already-published address: every card
carries the checkbox, the base URL is one value, and passkeys follow it. A
promote that would move an established network address (anything but the
loopback default, which is the checkbox's whole documented purpose) asks first,
naming both addresses.
