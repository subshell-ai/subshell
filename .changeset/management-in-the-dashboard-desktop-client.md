The node window is a setup-assistant-style flow: connect to a server, install the agent, enroll this machine, start the node service, and a connected screen that opens the control plane. Facts about how the agent runs moved to the control plane's Nodes page, which is where a person looking at several machines can see them together. Reset from the native app. The tray preference is a check item in the tray menu.
