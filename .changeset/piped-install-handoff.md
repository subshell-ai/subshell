`curl | bash` installs no longer hang at the terminal handoff: the installer script just execs `init`, which now acquires its own terminal with a never-blocking attach (and asks its questions off the attached fd), while a run that genuinely has no terminal takes its defaults and prints every default it took instead of saying nothing. `--yes` now answers every `init` question, including the tmux install and the background service, each announced by a line. `init` also asks whether to add `~/.local/bin` to the shell profile, the question the installer's PATH note used to be. The tmux preflight now runs first and its offer covers MacPorts and a Homebrew bootstrap (never attempted where no terminal could answer its password prompt, and refused outright by the server's own installer route), and declining or failing that install aborts `init` with nothing written and the rerun named. A new `--verbose` flag (or `SUBSHELL_VERBOSE=1`) raises the console transport to debug for the life of a hand-invoked run, HTTP request lines included, file logging and the debug-logging setting untouched, and either spelling is refused together with `--json`.
