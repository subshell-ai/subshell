The sidebar's version line opens the update screen

Inside Subshell Server, **Subshell Server 0.10.1** in the sidebar footer is now
a button that opens the update screen. It said the version and led nowhere,
which was the last place in the app where knowing it did you no good: "no
update known" is not "up to date" — the daily check may not have run today, or
may not have answered — and the screen it opens finds out.
