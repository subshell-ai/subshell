The server desktop assistant gains a sidebar rail of standing options — Status, Update, How it runs, Addresses — on an onboarded machine's standing screens, and only there: the first-time experience, reset, permissions and boot stay full-window. The recovery screen's Show Details disclosure is gone; its facts, log tail and last output render inline in the Status section, fed while the section is up.
