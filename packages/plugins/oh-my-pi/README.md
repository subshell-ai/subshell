# Oh My Pi plugin for Subshell

`@subshell-ai/plugin-oh-my-pi` launches the `omp` CLI from Subshell. It provides
model, provider, and thinking settings, automatic per-launch MCP
configuration, and sidebar subagent monitoring with view switching. Install and authenticate Oh My
Pi separately on each node where you want to run it.

See the [Oh My Pi guide](https://docs.subshell.sh/agents/oh-my-pi) for setup
and supported behavior. The integration is verified with Oh My Pi 18.18.7.
Automatic conversation resumption and attention hooks aren't supported.
