# Oh My Pi plugin for Subshell

`@subshell-ai/plugin-oh-my-pi` launches the `omp` CLI from Subshell. It provides
model, provider, and thinking settings, plus automatic per-launch MCP
configuration. Install and authenticate Oh My Pi separately on each node
where you want to run it.

See the [Oh My Pi guide](https://docs.subshell.sh/agents/oh-my-pi) for setup
and supported behavior. The integration is verified with Oh My Pi 18.12.6.
Automatic conversation resumption, attention hooks, and sidebar subagent
monitoring aren't supported.
